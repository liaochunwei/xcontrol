# 切片d：目录清单、进度 UI、校验完善

> 父任务：11-26-file-transfer；依赖切片 b/c。

## Goal

把「能传」打磨成「好用」：目录递归清单、传输进度 UI、校验与失败策略、可配置项收口。

## Requirements（开工时细化）

- R1 目录：顶层清单先行（条目数/深度上限），子树在拉取该条目时再展开（清单不在复制瞬间爆炸）。
- R2 进度 UI：托盘/通知进度（已传字节/总字节、当前条目），取消入口。
- R3 失败策略定稿：部分成功（成功的条目照常挂板 + 失败清单提示）的边界与文案。
- R4 可配置：总量上限、超阈值确认开关、暂存位置、prefetch（收到清单后台预拉，默认关——尊重「粘贴时才传输」的默认语义）。
- R5 断点续传评估（offset 已在协议中，评估重连后续传 vs 重传的成本，结论记 ADR 或 docs/02 修订）。

## Acceptance Criteria（开工时细化）

- [ ] 目录复制实测（含深树/大目录清单上限路径）、进度可见、取消生效、部分成功提示正确。
- [ ] 配置项进设置窗口并持久化（docs/06 惯例）。
- [ ] 质量门全绿。

## Out of Scope

- FR-7.1 共享文件夹 / FR-7.2 拖放（另行立项）。
