# 切片c：粘贴拦截物化（透明跨设备粘贴）

> 父任务：11-26-file-transfer；依赖切片 b（通道拉流）。本切片达成「像本地一样」的最终体验。

## Goal

注入路径拦截粘贴键：pending 槽有货且未失效时，先拉流物化挂板，再注入粘贴键——
用户全程 Cmd+C / Cmd+V，无托盘动作。

## Requirements（开工时细化）

- R1 拦截点在 XControl 自身的注入路径（KVM 天然钩子），零系统级 hook；文本粘贴路径零改动（NFR-1 不回退）。
- R2 触发条件：pending 文件槽有货 + 代次未失效；物化期间粘贴键挂起，进度经托盘/通知呈现，可取消。
- R3 物化失败（源离线/文件消失/用户取消）→ 粘贴键按取消后的状态处理（不注入或注入空操作 + 明确提示），**不得把挂起的键注入成错误行为**。
- R4 物化后挂板行为与本地一致（含文本应用场景，依 docs/05 §8 实机复核结论）。
- R5 防回环：物化挂板进入写入自标记（docs/04 §8 指纹规范形）。

## Acceptance Criteria（开工时细化）

- [ ] 双机实测：Finder 复制 → 从机资源管理器 Ctrl+V，文件落地，粘贴延迟 = 传输时长且进度可见。
- [ ] pending 槽失效后（复制了文本）粘贴行为与无文件槽时完全一致（回归保护）。
- [ ] 输入延迟基准不回退（NFR-1 回归）。
- [ ] 质量门全绿。

## Out of Scope

- OS 原生惰性粘贴（mac file promise / win FILEDESCRIPTOR，P2 增强）；目录递归（切片 d）。
