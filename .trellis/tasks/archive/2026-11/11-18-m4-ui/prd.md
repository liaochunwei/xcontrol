# M4: 设置编辑器与首次运行向导

## Goal

gpui 设置窗口内嵌页补全 + 首次运行向导（FR-6.3）——M4 出口"全程无命令行完成配对与使用"的最后一块。mac 本机可全链路实测（AX 自动化）。

## Requirements

1. **首次运行向导**（FR-6.3 + docs/06 §3）：检测"无配置文件"→ 启动即弹全屏向导流——角色选择 → 安全码（输入/生成建议）→ 网段（默认自动）→ 权限引导页（按平台渲染：mac 辅助功能检测 `check_accessibility(prompt:false)` 状态 + 跳转按钮；win/Linux 对应项）→ 完成（写 config + 进运行时）。跳过选项（CLI 用户）。
2. **设置页补全**（docs/06 §4 信息架构的最小可用集）：
   - 状态页（已有）补：在线从机列表（点击切换）；
   - 映射页：预设下拉（8 预设）+ 直通开关 + 规则表（增删改简化版——展示 + 删除 + 单条新增表单，录制控件 M5）；
   - 热键页：四键展示 + 修改（简化为组合键文本输入 + 校验，录制控件 M5）；
   - 剪贴板页：范围/上限/格式开关（文本开，image/html M5 灰置）；
   - 通用页：语言（zh-CN 固定 v1）/主题（跟随系统）/日志级别下拉/自启开关（接 Autostart trait）；
   - 关于页：版本/协议版本/许可 + 导出诊断包（logs 目录 zip——简化为路径展示 + reveal）。
3. **配置修改即时生效**（docs/06 §4 交互规范）：表单改动写 TOML（xcontrol-config save）+ 关键项即时应用（日志级别/直通/自启）；破坏性操作（改安全码/角色）确认框；**热加载缺口**：config 重载钩子 M1 起延后——本任务裁定改动生效方式（即时 vs 重启），映射/热键等会话内生效项报告实际行为。
4. **单实例语义**（docs/06 §2）：二次启动进程唤起已有实例窗口（mac on_reopen 已有；单实例锁 + IPC 最小实现或检测到已有实例时 `--status` 提示——实现裁定，最简可用优先）。
5. **AX 可自动化**：全部控件可达（gpui AccessKit 默认）——向导流与映射页 AX 实测脚本。

## Acceptance Criteria

- [ ] 无配置启动 → 向导自动弹出 → 走完四步 → config.toml 生成且字段正确 → 运行时按所选角色启动（AX 实测）
- [ ] 权限引导页显示真实检测状态（本机已授权 → 绿色；未授权 → 引导按钮）
- [ ] 五个设置页可打开、改动落盘（TOML diff 验证）、即时生效项实测（日志级别）
- [ ] 映射页改动 → 会话内映射行为变化（重启会话生效路径实测并文档化）
- [ ] check-deps/clippy/fmt/test 全绿；gpui 编译告警 0
- [ ] mac AX 实测：向导四步 + 映射页增删规则 + 通用页日志级别切换

## Notes

- gpui-kit 组件（Form/Input/Switch/Sidebar）docs/06 §1 已选型——用组件库而非裸 gpui（spike 关闭了组件库 feature——本任务开启，注意编译面与版本源一致性）。
- 本任务是 M4 最重的 UI 任务；"最小可用"优先：规则编辑器不求录制控件，向导不求动画。
- 配置即时生效框架（watch + ConfigReload 事件）docs/01 §5 提过但 M1 延后——本任务裁定并落最小钩子（设置页改动 → 运行时各组件读最新 config 的路径），不做文件监听。
