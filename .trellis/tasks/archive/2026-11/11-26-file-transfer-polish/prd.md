# 切片d：目录清单、进度 UI、校验完善

> 父任务：11-26-file-transfer；依赖切片 b/c。

## Goal

把「能传」打磨成「好用」：目录递归清单、传输进度 UI、校验与失败策略、可配置项收口。

## Requirements（2026-11-26 开工定稿）

- R3 部分成功策略（先做）：逐条目拉取中任何条目失败不再废弃整单——已成功
  条目照常挂板（按 pending 顺序），失败条目记入失败清单提示；「会话完成」
  判定 = 已完成 + 已失败 ≥ 条目总数。
- R2 进度与取消：拉取进行中托盘条目显示进度（已完成条目/总数），出现
  「取消文件传输」入口（FileCancel 已有 wire 面）——取消 = 终止未完成条目 +
  已成功条目照常挂板。
- R4 配置面（最小可用）：config `[file_transfer]` 表（enabled / max_bytes /
  confirm_threshold_bytes）——发送端超上限不发布；接收端超协商上限拒绝
  （FileRefRx 既有面接线）；超确认阈值需二次点击。
- R1 目录（FileExpand 接线）：PullReq 命中目录条目 → 源端有界枚举（深度 4/
  条目 512 上限）→ FileExpand 帧 → 接收端下标空间增长 + 自动续拉文件子条目
  （递归目录经再展开）。
- R5 断点续传评估结论入档：v1 选**重传**（LAN 带宽下重传成本低于续传状态机
  复杂度；offset 保留协议面），结论入 docs/02 修订注记。

## Acceptance Criteria（开工时细化）

- [ ] 目录复制实测（含深树/大目录清单上限路径）、进度可见、取消生效、部分成功提示正确。
- [ ] 配置项进设置窗口并持久化（docs/06 惯例）。
- [ ] 质量门全绿。

## Out of Scope

- FR-7.1 共享文件夹 / FR-7.2 拖放（另行立项）。
