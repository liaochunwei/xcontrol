# 规范先行：ADR-0004 与五份规范修订

> 父任务：11-26-file-transfer（design.md 是本任务的技术源材料）。
> 本任务只改文档，不改代码——协议红线「先文档后代码」（AGENTS.md / docs/02 头部）。

## Goal

把跨设备文件复制粘贴（粘贴时才传输）的需求、协议、剪贴板语义、平台路径与安全面
写入事实源，使后续代码切片（a–d）有据可依：

1. **ADR-0004**：文件通道拓扑（独立第三条 TCP）与物化策略（统一 stage-then-mount）。
2. **docs/00**：FR-7.3 新增（含 AC）；§6 非目标表述修订（文件内容传输从"不做"改为"规划于 FR-7.x"的有界表述）；FR-4.6 与 FR-7.3 的关系备注。
3. **docs/02**：XCP minor 1.1 → 1.2；文件域 kind 0x58–0x5F；wire 类型钉死；文件域防护规则（u64/超时缩放/索引寻址/清单上限）。
4. **docs/04**：文件引用剪贴板规范——检测格式、回环指纹规范形、pending 槽与代次失效、物化流程、与 §3「推送决策」的辨析。
5. **docs/05**：四平台文件引用读写矩阵 + 实机复核项。
6. **docs/07**：文件传输安全清单（索引寻址防任意读、磁盘耗尽、阈值确认、清单上限）。

## Requirements

- R1 所有新增内容带 FR-7.3 编号引用，交叉引用（docs 互链）完整可点击。
- R2 协议变更按 docs/02 修订记录惯例：标注日期、任务号、兼容性论证（新 kind 随 minor 提升，1.1 对端"未知 kind 跳过"无损降级）。
- R3 不确定的平台行为（mac TextEdit 粘贴文件行为、NSFilePromiseReceiver 粘贴路径支持）**不得凭记忆断言**，记为实机复核项（docs/05 §8 惯例）。
- R4 CHANGELOG Unreleased 新增 Added 条目（规范层面）。
- R5 `.trellis/spec/` 规则卡检查：rust-core / rust-platform 卡是否需要补文件域指针，需要则同步。
